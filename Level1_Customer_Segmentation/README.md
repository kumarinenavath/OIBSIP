# Customer Segmentation Analysis Using K-Means

## Project Overview
This project focuses on grouping customers based on their annual income and spending behaviour using the K-Means clustering algorithm.

## Dataset
Customer Personality Analysis dataset from Kaggle.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Steps Performed
1. Loaded and explored the customer dataset.
2. Handled missing values in the Income column.
3. Created Total Spending and Total Purchases features.
4. Scaled the selected features using StandardScaler.
5. Applied K-Means clustering to group customers into four segments.
6. Visualized customer groups using scatter plots and bar charts.
7. Analysed the characteristics of each customer segment.

## Key Findings
- Identified four customer clusters.
- Compared customer groups based on income and spending.
- Identified high-value and low-spending customer groups.
- Observed an income outlier that requires further investigation.

K-Means clustering helps businesses understand customer behaviour and identify different customer groups. This analysis can support better marketing strategies and customer targeting.
