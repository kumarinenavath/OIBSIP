# Retail Sales Analysis

## Project Description
This project focuses on analyzing online retail sales data to understand sales performance, customer purchasing behavior, and product trends.

## Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Tasks Performed
1. Loaded and explored the retail sales dataset.
2. Checked missing values and duplicate records.
3. Cleaned the dataset.
4. Calculated total sales using Quantity and Unit Price.
5. Analyzed sales by country.
6. Created visualizations to understand sales trends.
7. Identified important business insights.

## Key Findings
- Total Revenue: 8,278,519.42
- Total Orders: 22,190
- Total Customers: 4,372
- Total Products: 3,896
- Countries Covered: 37

## Conclusion
The analysis helped identify sales patterns, customer behavior, and business performance. These insights can support better business decisions and sales strategies.
