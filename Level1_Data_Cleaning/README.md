# Data Cleaning Using Python

## Project Overview
This project focuses on cleaning and preparing a dataset using Python. The goal is to improve data quality and make the data suitable for further analysis.

## Tools and Technologies
- Python
- Pandas
- Google Colab

## Steps Performed
- Loaded the dataset using Pandas.
- Explored the dataset structure.
- Checked for missing values.
- Checked for duplicate records.
- Cleaned the data where required.
- Saved the cleaned dataset.

## Project Files
- `OIBSIP_Task1_Data_Cleaning (1).ipynb` – Python notebook.
- Cleaned dataset – output file.

## Conclusion
Data cleaning is an important step in data analysis. It helps remove errors, handle missing values and duplicates, and improve data quality. This project provided practical experience in preparing a dataset using Python and Pandas.
